# SellerMate — সেলার খাতা (MVP v0.1)

ছোট অনলাইন বিক্রেতাদের জন্য বাংলা CRM: গ্রাহক, বাকি হিসাব, ফলো-আপ, কল ও WhatsApp।

> এই কোড `npm install` / `npm run build` দিয়ে এখনো চালিয়ে পরীক্ষা করা হয়নি। প্রথম deploy-এর Vercel build log দেখে নিন।
> সাহায্য লাগলে error লেখাটা কপি করে পাঠান।

## এখন যা কাজ করে

- **হোম:** মোট বাকি, এ মাসের বিক্রি ও পাওয়া টাকা, আজকের ফলো-আপ, সবচেয়ে বেশি বাকি
- **গ্রাহক:** যোগ, খোঁজা (নাম/নম্বর/ঠিকানা), ফিল্টার (সব / বাকি আছে / ফলো-আপ), তথ্য বদলানো, মোছা
- **হিসাবের খাতা:** "বিক্রি" যোগ করলে বাকি বাড়ে, "টাকা পেলাম" দিলে কমে। প্রতিটি লাইনে চলমান বাকি দেখায়
- **কল / WhatsApp / তাগাদা:** এক ট্যাপে। তাগাদার মেসেজ আগে থেকে বাংলায় লেখা থাকে (দোকানের নামসহ)
- **ফলো-আপ রিমাইন্ডার:** তারিখ দিন, সেদিন হোমে দেখাবে (দেরি হলে লাল)
- **ব্যাকআপ:** JSON ফাইলে নামানো ও ফিরিয়ে আনা
- **ফোনে অ্যাপের মতো:** Chrome মেনু → Add to Home screen
- বাংলা ও ইংরেজি দুই ধরনের সংখ্যাই টাইপ করা যায়

## Known limitations (সৎ তালিকা)

- **ডেটা শুধু ওই ফোনের ব্রাউজারে থাকে।** লগইন নেই, ক্লাউড সিঙ্ক নেই। ফোন বদলালে বা ব্রাউজার ডেটা মুছলে হারাবে (ব্যাকআপ নিন)।
- একাধিক ডিভাইস বা কর্মচারীর শেয়ারিং নেই।
- Payment/subscription নেই। এখনো কিছু বিক্রির ব্যবস্থা তৈরি হয়নি।
- অফলাইন সাপোর্ট (service worker) নেই। ইন্টারনেট ছাড়া প্রথমবার খুলবে না।
- WhatsApp মেসেজ নিজে থেকে যায় না; WhatsApp খুলে মেসেজ লেখা থাকে, আপনি Send চাপেন।
- ডেটা encrypt করা নয় (ফোনেই থাকে, কিন্তু ফোন কেউ খুললে দেখা সম্ভব)।

## Local test

```bash
npm install
npm run typecheck
npm run build
npm run dev   # http://localhost:3000
```

## Deploy (GitHub + Vercel)

1. GitHub-এ নতুন repo (`sellermate`) বানান, কোড push করুন।
2. vercel.com → Add New → Project → repo Import → Deploy। কোনো environment variable লাগে না।

## পরের ধাপ

1. Supabase দিয়ে লগইন + ক্লাউড সিঙ্ক (ফোন বদলালেও ডেটা থাকবে)
2. অফলাইন সাপোর্ট (PWA service worker)
3. Excel/PDF রিপোর্ট ও বাকির তালিকা শেয়ার
4. bKash/Nagad পেমেন্ট নোট, কুরিয়ার (Pathao/Steadfast) অর্ডার ট্র্যাকিং
5. Free বনাম Pro প্ল্যান (গ্রাহক সংখ্যা, ক্লাউড ব্যাকআপ)
